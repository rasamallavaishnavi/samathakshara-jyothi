# Samathakshara Jyothi Seva Samithi Website

## Free deployment
1. Create a GitHub account.
2. Create a new public repository, e.g. `samathakshara-jyothi`.
3. Upload all files from this folder.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. GitHub will provide an HTTPS address such as `https://YOURUSERNAME.github.io/samathakshara-jyothi/`.

## Important
